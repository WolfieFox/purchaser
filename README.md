# Purchaser

Quick and dirty purchase sprite generator for Timberwolf's Trains and
other sets using the same format of tracking table and sprite directory.

## Usage

The following command-line flags are available:

* `-s <list>` or `-scales <list>` : Comma-seperated list of scales to render at (analogous to GoRender `-s <list> -u`) Default: `-s 1,2`
* `-i <list>` or `-ignore <list>` : Comma-seperated list of templates to skip. Default: `na,tender`
